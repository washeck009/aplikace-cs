# Prompty pro Claude Code

Vkládej je do Claude Code (spuštěného ve složce repa) **postupně, jeden po druhém**. Po každé etapě
aplikaci vyzkoušej podle bodu „Hotovo, když“ a teprve pak pokračuj další etapou.

| Etapa | Obsah |
|---|---|
| 1 | Základ: struktura repa, backend (tabulka, přihlášení PINem, API), PWA kostra s rozcestníkem, nasazení na GitHub Pages |
| 2 | Kontrola lokace na čtečce (skenování, ✓/✗/upravit, přidání zboží, offline fronta, fotky) |
| 3 | Úkoly, Blíží se expirace, plánovač kontrol |
| 4 | PC část: přehled, záznamy + export, správa, importy z ERP |
| 5 | Týdenní report, převod dat z AppSheet, doladění na pilot |
